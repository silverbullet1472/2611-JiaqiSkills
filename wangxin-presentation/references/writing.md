# 文案与信息组织

## 事实先于表达

保住事实、原意、证据强度和来源对应，再满足受众与用途，最后调整措辞。材料缺失或矛盾时记录具体缺口；不补造数字、上线情况或现场情节。计划、预估、试点、相关等词若影响结论就保留，不能把局部结果改写为整体表现。

用户给定受众时沿用；未指定且上下文无法推断时，按非专业听众组织背景与术语解释，不假定所有听众熟悉技术。先选择听众需要知道的信息，再解释必要术语，不把技术报告逐段压缩成页面。

## 每页有清楚任务

用一句普通话概括本页要让人看懂什么。可以包含多项内容，但只有一个主要任务。顺序随讲解需要安排，不强制结果先行或固定章节比例。区分进展、比较、原理、案例、过程与计划。

标题说明具体内容，例如“研究目标与内容”“材料核验流程”。只有有依据且需要被记住的判断才写成结论标题。普通工作不包装成突破，不用“这一页告诉你”“我们先来看”等主持式路标，不以诗行断句制造气氛。

## 正常书面语

- 写准确的对象、动作与结果，用“整理案例材料”代替“完成对案例材料的系统性整编赋能”。
- 删除没有增加信息的口号、空泛评价、机械排比和翻案句；保留真实区别、必要术语与完整步骤。不按禁词表机械替换。
- 长句先找谁做什么，把时间、条件和范围放在对应动作附近；压缩不能删掉否定范围、归属与不确定性。
- 保持名称一致，代词指向清楚。自然表达来自准确克制，不靠聊天口吻、网语或随机短句。
- 标签可用短语，因果与条件需要完整句。标题、引导语、图注和正文分别承担职责，避免反复说同一个判断。

## 关系决定布局

| 信息关系 | 优先形式 |
|---|---|
| 先后与依赖 | 有方向的流程、时间线，标明必要分支条件 |
| 两个方案比较 | 左右对照、共同坐标轴、差异表 |
| 主次与包含 | 树形、嵌套、面积及字号层级 |
| 字段对应 | 表格或对齐列表 |
| 真实材料 | 原图、截图、文件结构，文字补充画面没有表达的内容 |
| 单个重点 | 留白、一句判断或一个主数字 |

重要信息获得更大的面积与字号，不因数字精确就自动放大。比较须明确对象、共同尺度和差异；核对单位、日期、样本、分母与基准。图表面积、刻度与比例不能夸大差异。

## 工作资料与上屏内容

来源、核验状态、引用对应、统计说明和制作注意事项保存在工作文档。默认不增加可见“来源”“待核”“查看依据”按钮与长脚注，但影响判断的条件必须自然留在标题或正文中。截图自带的署名日期保留。真实引语保留原话，转述时保留归属。

## 最后回读

逐页看标题与正文是否对应、是否重复图片、是否混入另一主题、是否因排版丢了条件、是否夸大证据、是否有为填空间而加的文字。语言已经自然准确时保留，不为显示改动而换词。只评价时不修改；局部修改不扩大到整套重写。
