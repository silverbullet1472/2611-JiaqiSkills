# 制作接口

`scripts/render_deck.py`只使用Python 3.12标准库。输入是本机可信JSON，正文允许HTML；它不是面向互联网用户输入的渲染服务。资源路径相对输入JSON所在目录。输出为图片内嵌的单文件HTML。

```json
{
  "title": "项目进展与工作安排",
  "title_lines": ["项目进展", "与工作安排"],
  "unit": "本次汇报单位",
  "date": "2026年11月",
  "closing": "请批评指正，谢谢！",
  "pages": [
    {
      "title": "当前工作进展",
      "chapter": "工作进展",
      "topic": "已完成工作",
      "html": "<div class=\"cols\"><div><h3>材料整理</h3><p>填写有依据的工作进展。</p></div><figure><button class=\"image-button\" aria-label=\"放大运行界面\"><img src=\"assets/运行界面.png\" alt=\"运行界面\"></button></figure></div>"
    }
  ]
}
```

运行：`python <skill目录>/scripts/render_deck.py <输入.json> <输出.html>`。

每页必需`title`、`chapter`；可选`topic`、`id`。`html`也可替换为`html_file`，从本地文件读取正文。可在顶层提供`content_css_file`载入本次正文布局样式，主题样式最后应用。页面先后顺序由`pages`决定，章节按首次出现排列；同章页面应连续。导航跳转至对应章、主题的第一页。章节与主题名称填写纯标题，两级导航不添加数字编号。生成器自动增加封面、目录及结束页，因此总页数为正文页数加3。

`.cols`提供两栏，`.lead`为引导语，`.callout`为少量重点说明，`.metrics/.metric`展示有意义的主数字，普通表格使用`table/thead/tbody`。复杂流程、时间线、对照等由本次正文HTML/CSS实现，不用通用卡片替代。不要依赖演示页码选择器维护新材料；优先为有独立布局的页面命名语义类。

图片`src`使用双引号、本地相对路径或data URI。远程图片先下载到素材目录；输出仅允许主题中指定的小米官方MiSans字体CSS及字体请求；其他脚本、布局样式、图片均内嵌，不能增加其他网络依赖。不要向正文写入脚本；交互由播放器提供。图片按钮使用`.image-button`，点击放大，Esc或关闭按钮返回。装饰背景不包进图片按钮。

## 验收

先运行生成器并检查总页数，再用浏览器等待在线字体加载完成后查看全部页面，至少在一个常用桌面尺寸目视查看封面、目录、数据密集页、图表、表格及结束页。可批量截图拼接检查视觉一致性，再放大有疑点的页。检查正文626px区域内的实际边界；少量字体边界余量不等于可见裁切，截图与实际重叠决定是否修复。

验证正式目录、两级导航、全部页面弹窗、翻页键、滚轮、图片弹窗和Esc；打印预览或生成PDF检查分页及背景。全屏使用按钮或F键，退出用Esc。若环境无法实际验证某项，交付时说明，不能以静态代码检查代替。
