# 示例素材

示例来源为用户指定的《数字孪生处-面向河湖遥感图斑复核的AI辅助研判技术研究-v2.pptx》。只节选研究内容，重新排版以演示颜色、导航、表格与鼠标高亮；不是原PPT的完整转换，也不将原计划表述为当前进展。

| 示例正文页 | 来源PPT页码 | 处理 |
|---|---|---|
| 研究目标 | 13 | 保留研究性质，概括目标与四项内容 |
| 知识库与数据集构建 | 14 | 保留知识与数据两项建设工作 |
| 原型开发与验证迭代 | 16 | 将原型、评测、优化整理为流程 |
| 实施计划 | 17 | 按原时间段概括阶段与工作，明确为计划 |

封面题目、单位、日期来自第1页，装饰素材与原PPT来源见[视觉约定](design.md)。不包含人员名单、经费页或其他业务汇报的统计、截图、采购内容。

输入：`assets/example.json`；正文样式：`assets/example.css`。在任意目录运行：

```text
python <Skill目录>/scripts/render_deck.py <Skill目录>/assets/example.json <输出目录>/申报材料示例.html
```

生成四页正文，加封面、目录、结束页，共七页。所有图片从Skill自带素材读取并内嵌，不依赖原PPT或原工作区。完整PPT无需进入分发包；未来需要追加素材时，先确认具体页及内容可复用范围。

示例仅用于展示整体风格和播放效果。结构图、表格及其他正文布局由AI按实际内容设计，不以示例页面作为固定模板。
