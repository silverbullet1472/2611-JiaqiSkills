# 页面文案

## 标题先说明页面内容

标题的首要作用是帮助观看者判断这一页在讲什么。流程、界面、材料和数据展示可以直接使用准确名称。

- 推荐：用户访谈记录
- 推荐：数据迁移流程
- 推荐：三种方案成本比较
- 避免：这一页带你看看用户到底怎么想
- 避免：数据从这里出发，最终抵达新的系统

只有页面确实承担阶段结论时，才使用结论型标题。结论型标题要直接写判断，不先制造悬念。

## 标题分量服从事情的重要程度

判断一个数字或动作是否应该进入标题时，先问它是否影响观看者对当前主题的理解。常规清洗、格式转换、路径调整和文件复制通常适合放在流程节点或正文中。

不要因为数字精确就把它放大。数字应当帮助理解规模、差异、变化或结果。

## 不模拟口语

视觉汇报中的自然表达来自准确和克制，不来自聊天式开场。

- 少用“这次”“这一轮”“这样的”“采回来的”等缺少具体对象的指示词。
- 不写“我们先来看”“你可能会问”“说到这里”等主持式过渡。
- 不为了显得有人说话，把普通栏目标题改成长句。
- 不用断行制造停顿、悬念或诗意。

## 按语义处理模型腔和生硬句法

先判断表达是否阻碍理解、重复信息或夸大结论，再决定是否修改。下表中的表达不是禁用词；真实区别、必要术语和有用结构优先保留。同一问题只处理一次，不叠加规则反复改句子。

| 症状与触发条件 | 修改动作 | 保护边界与复查 |
|---|---|---|
| 翻案、递进或排比只是在抬高评价，没有增加信息 | 用具体对象和动作重写，必要时拆开不同层级的判断 | 保住真实对比、排除项和作者判断；换成另一组对称连接词不算解决 |
| 抽象名词与弱动词掩盖动作，如“完成对流程的优化” | 恢复直接动词；材料已有细节时再说明改了什么 | 保留规范术语和责任主体，不从“优化”擅自补出具体措施 |
| 条件短语、多层定语把句子主干推得太远 | 先找谁做什么，再把条件、时间和范围放到相应动作附近 | 不删掉适用范围；页面标签无需强凑完整主谓句 |
| 连续代词、被动句或同义换名使指代难懂 | 在语境清楚处省略重复，必要时恢复对象名称 | 重复专名能消歧、被动能说明受事或责任时保留 |
| 动词与对象搭配生硬，或术语被故意换成口语 | 改为目标语体中自然的表达 | 保留行业惯用语、产品名及真实引语，不生造“接住价值”等替代语 |
| 句句同长度、段段同结构，或重复解释同一判断 | 按信息职责拆并句子，删除语义重复 | 参数、步骤、责任清单和对照项可以平行，不按条目数量判错 |
| 主持式路标、连接词、标点反复代替实际关系 | 删除空引导，重写句间关系后再选标点 | 保留必要导航、因果、条件、术语解释和真实停顿 |
| 口号、积极收尾或连续限定词没有增加信息 | 删去空话和重复限定，让事实或行动承担表达 | 不把“可能有效”压成“有效”；作者明确判断不能因抽象就全部删除 |

完成后回读信息是否更容易理解、事实和语气是否等义。不要用随机短句、错字、网语或第一人称制造自然感。

## 压缩时保住判断依据

- 数字与单位、样本范围、比较基准、时间窗口一起核对。删字不能把局部结果改成整体表现。
- 合并要点前区分语义重复与独立事实；相似句式不意味着内容重复。
- 改标题时检查证据强度。“计划”“试点”“初步”“相关”等词如果决定结论含义，就不能为简短而删除。
- 真实引语默认保留原话；可以选取不歪曲原意的片段并明确省略，或改为注明归属的转述，但不能改字后继续冒充直接引语。
- 术语、代码、公式、固定定义和用户指定原文按其功能保护，优先修改周边说明。
- 在制作文档中维护陈述与来源的对应；缺失的口径或出处记为待补。默认不上屏展示来源标识、待核小字或来源入口，按SKILL.md的“演示画面与制作备注”执行。

## 页面元素各做一件事

- 标题说明页面主题或关键结论。
- 引导语补充必要背景、条件或范围。
- 数据卡只放数字、单位和简短口径。
- 图注说明画面对象、时间或来源。
- 按钮写清点击后发生什么。
- 页面正文解释画面没有表达清楚的内容。

图片已经展示界面时，不再用一段话复述界面。流程图已经表示顺序时，正文只说明关键条件或例外。

## 控制文字长度

- 标签优先使用准确短语。
- 条件、边界和因果关系使用完整句子。
- 一段只处理一个问题。
- 删除不能增加事实、关系、判断或操作的信息。
- 不为视觉对齐而补满无用文字。
