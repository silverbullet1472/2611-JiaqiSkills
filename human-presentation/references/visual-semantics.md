# 视觉关系

## 先判断关系，再选择组件

版式承担信息结构。不要因为卡片容易制作，就把所有内容都做成同等大小的卡片。

| 内容关系 | 优先形式 | 避免形式 |
|---|---|---|
| 有先后和依赖 | 流程图、时间线、带方向的步骤 | 无方向的并列色块 |
| 两个对象比较 | 左右对照、同轴条形、差异表 | 把对象、指标和结论排成一行同级卡片 |
| 主次或包含关系 | 树形、嵌套、面积和字号差 | 所有项目同色同面积 |
| 字段逐项对应 | 表格、对齐列表 | 分散卡片导致视线反复跳动 |
| 一个来源影响多处 | 分支图、连接线 | 用文字重复说明每条关系 |
| 真实材料展示 | 原图、截图、缩略图、文件结构 | 用装饰插画替代真实对象 |
| 单个重点结论 | 留白、一个主数字或一句结论 | 多张装饰性数据卡争夺注意力 |

## 对比必须形成对照

对比页面至少明确三个要素。

1. 比较的对象是谁。
2. 使用什么共同尺度。
3. 差异体现在哪里。

把“对象名称、对象指标、差异倍数、辅助说明”排成四个同级色块，会削弱比较关系。应当把两个对象放在对立位置，把共同尺度或差异放在两者之间或同一坐标轴上。

比较时同步检查时间窗口、样本、单位和统计口径。不同口径的数据应标出差别，无法直接比较时不要用倍数、排名或箭头暗示可比。坐标轴截断、面积编码或遗漏基准可能放大差异，须采用与数值含义一致的编码并明确必要标注。

## 流程必须显示方向

- 节点名称写动作或状态，不写空泛概念。
- 箭头只表示真实的先后、转换或引用关系。
- 分支需要标明触发条件，不能只画分叉。
- 文件、数据和结果之间存在索引或引用时，使用连接线并写明“通过什么字段指向什么对象”。
- 同时发生或先后出现不自动构成因果；时间线只能证明顺序时，不改画成因果链。计划步骤、试点状态和已完成动作应能区分。

## 图文分工

- 画面负责展示对象、关系和差异。
- 文字负责命名、补充条件和说明边界。
- 图注不替画面总结意义。
- 视觉已经表达清楚的关系不再写成长段解释。

## PPT 与滚动式 HTML

PPT通常以离散页面组织内容。滚动式HTML可以让段落高度随内容变化，不必模拟固定幻灯片比例。

- PPT中控制每页任务和视觉焦点。
- 滚动式HTML中允许长流程、完整表格和连续材料自然展开。
- 不因使用HTML就无限堆字；仍需保持段落主题和层级清楚。
- 不因使用PPT就把所有内容强塞进一页；必要时拆分页面。
